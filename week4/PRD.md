# PRD (Product Requirements Document)
# AI Physics Course — GitHub Linked Simulator

> **문서 버전:** 1.0 | **작성일:** 2026-05-03

---

## 1. 제품 개요

### 1.1 목적
TensorFlow/Keras 기반 신경망이 물리 법칙을 어떻게 학습하는지 **시각적으로 체험**할 수 있는 교육용 시뮬레이터. 학습 과정을 실시간으로 모니터링하고, 실험 결과를 GitHub에 자동으로 기록한다.

### 1.2 핵심 가치
| 가치 | 설명 |
|---|---|
| 즉각적 피드백 | 학습 중 Loss 곡선과 예측 피팅이 실시간으로 업데이트됨 |
| 재현 가능성 | 실험 조건(Epochs, LR)과 결과가 마크다운 로그로 자동 누적 저장 |
| 교육적 명확성 | 과적합·과소적합 등 핵심 개념을 하나의 UI에서 비교 체험 가능 |

## 2. 사용자

| 사용자 | 목적 |
|---|---|
| AI/물리 수업 수강생 | 신경망의 물리 함수 근사 과정을 직접 실험 |
| 강의자 | 과적합·학습률 등 개념을 라이브 시연 |

## 3. 기능 요구사항

### 3.1 Lab 실험 목록

| Lab | 실험 주제 | 상태 |
|---|---|---|
| Lab 1 | 1D 사인 함수 근사 (데이터 셔플링 포함) | ✅ 구현 완료 |
| Lab 2 | 포물선 궤적 회귀 | 🔧 준비 중 |
| Lab 3 | 과적합(Overfitting) 데모 — 노이즈 데이터 + 깊은 망 | ✅ 구현 완료 |
| Lab 4 | 진자 운동 예측 (RK4 수치 적분 데이터) | 🔧 예정 |

### 3.2 UI 기능

- **Lab 선택 드롭다운**: 실험 전환
- **Epochs 슬라이더**: 10 ~ 500 범위 조절
- **Learning Rate 선택**: 0.01 / 0.001 / 0.0001
- **실시간 그래프**: Loss 곡선(좌) + 예측 피팅(우) 동시 표시
- **터미널 로그**: 학습 상태 텍스트 출력

### 3.3 GitHub 아티팩트 자동 생성

학습 완료 시 다음 파일이 자동 생성된다:

| 파일 | 위치 | 내용 |
|---|---|---|
| PNG 그래프 | `outputs/{lab}_{timestamp}.png` | 최종 Loss 곡선 + 예측 피팅 이미지 |
| 실험 로그 | `experiment_history.md` | 타임스탬프·파라미터·최종 Loss 누적 테이블 |

## 4. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| UI 반응성 | 학습 스레드와 UI 스레드 분리 — UI 블로킹 없음 |
| 업데이트 빈도 | 5 epoch마다 예측 그래프 갱신 (UI 과부하 방지) |
| 확장성 | 신규 Lab 추가 시 `TrainingThread.run()`에 분기만 추가 |
| 로그 누적 | 앱 재실행 후에도 `experiment_history.md`에 이어서 기록 |
